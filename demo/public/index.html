This is a live authorization gateway with a mock payment provider behind it. You say what the user asked for and what an approver signed off, then you attempt any payment you like. Moat compares the two and decides. Everything below is yours alone and disappears when you stop using it.

Against a real chain

The same decision in front of a wallet on Base Sepolia, a public test network. The approved payment produces a transaction you can open in a block explorer; the forged one produces nothing, because Moat refuses before the wallet is asked.

Test networks and a mock provider; nothing here can move money that matters. Every verdict is written to a signed, hash-chained evidence record — the same one an auditor would read. The measured results, the attack corpus and the evidence format are in the repository.
